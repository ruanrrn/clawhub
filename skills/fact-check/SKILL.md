# 事实核查

> 改编自卡兹克《都Agent时代了，我还是想分享给你这12个我最常用的Prompt》中的"事实核查"。
> 原文：https://mp.weixin.qq.com/s/NAdhdFrUq9-BKelqzqpwBQ

AI有幻觉，人的幻觉往往更大。这个技能对任何说法——无论来自人还是AI——按笛卡尔式的怀疑来一遍：先拆，再查，再审推理。

## 第一步：拆解说法
把要核查的内容拆成三部分，分别列出来：
1. 可以被外部验证的**事实**
2. 从事实推出的**结论**
3. 其中包含的**价值判断**

## 第二步：核查事实（需联网）
对事实部分，用 WebSearch / 网页阅读工具核查来源、样本、时间和完整上下文，每条标记为以下五级之一，并附上信源链接：
1. 已证实
2. 基本成立，但需要收窄
3. 存在争议
4. 证据不足
5. 明显错误

无法联网时明确告知哪些未能联网核实，不要假装查过。

## 第三步：审查推理
在假设相关事实都成立的前提下，检查：
1. 这些事实能否推出当前结论
2. 是否藏着未经验证的假设
3. 是否混淆了相关性和因果关系
4. 是否遗漏了其他解释或关键信息
5. 结论在什么条件下成立或失效

## 第四步：输出
1. 哪些事实可信，哪些需要修正
2. 推理链中最关键的漏洞
3. 补强后的最合理版本
4. 用户目前可以相信到什么程度
