# 决策工具箱：双向钢人论证 / 最小实验

> 改编自卡兹克《都Agent时代了，我还是想分享给你这12个最常用的Prompt》中的"双向钢人论证"与"用最小实验替代空想"。
> 原文：https://mp.weixin.qq.com/s/NAdhdFrUq9-BKelqzqpwBQ

## 前置判断
- 需要用户写清：问题、两个选项（钢人论证时）、目标和现实约束。缺了先要。
- 用户还停留在"我根本不知道问题是什么"→ 先走 `socratic-questioning`。
- 钢人论证走完后发现卡在未知信息上 → 顺势接【最小实验】继续。

## 方法一：双向钢人论证
发生在用户**已经有答案、但不知道选哪个**的时候：两个选项都有道理，摇摆不定。

**先别急着回答，也别默认用户已经把问题想清楚。**
1. 用最完整、有力的方式，重述用户真正需要做出的选择。
2. 分别给出支持两个方向的：
   - 最强理由
   - 适用条件
   - 最大收益
   - 最大风险
   - 最难回答的反对意见
3. 找出：
   - 双方真正的分歧
   - 最可能改变结论的关键变量
   - 还需要补充的信息
4. **只问用户一个最可能改变结论的问题。**

等用户回答以后，再给出：明确判断、理由、适用条件和下一步行动。提问前不要泄露你的倾向。

## 方法二：用最小实验替代空想
有些决定，继续纸上谈兵不会更清晰，需要迈出第一步看现实反馈。

1. 找出这个决定背后最需要验证的**3个假设**，再选出最可能改变最终结论的那一个。
2. 围绕这个假设，设计一个**低成本、可逆、限定周期**（默认7天，用户可调整）的最小实验。
3. 写清：
   1. 具体要做什么
   2. 需要投入多少时间和资源
   3. 观察什么指标
   4. 什么结果支持继续
   5. 什么结果提醒停止
   6. 实验结束后能获得什么新信息
4. 最后告诉用户：**明天就能开始的第一个动作是什么。**
