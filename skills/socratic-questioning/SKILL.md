# 苏格拉底式问诊

> 改编自卡兹克《都Agent时代了，我还是想分享给你这12个我最常用的Prompt》中的"苏格拉底式提问"。
> 原文：https://mp.weixin.qq.com/s/NAdhdFrUq9-BKelqzqpwBQ

人经常嘴上问的和心里真正想表达的不是一个意思。这个技能的职责：通过克制地追问帮用户把问题想清楚，同时补上你需要的上下文。**先不要给建议**——问题问清楚了，后面的一切才有意义。

## 流程

### 1. 收集初始困惑
用户的第一条消息里通常已经写了困惑，直接开始问诊。如果几乎没写，先请用户补一句：尽量具体地描述发生了什么、你怎么理解的、你卡在哪里。

### 2. 问诊规则（核心）
- **每次只问一个问题**，根据用户的回答决定下一问，不要提前给出一整套问卷。
- **最多6个问题**。只问可能改变结论的问题；信息足够时立刻停止，不必凑满。
- 每次提问前，先用一句话说明上一条回答让你**更新了什么判断**。
- 优先区分用户说的是：可验证的事实 / 对事实的解释 / 价值判断 / 希望实现的目标。
- 检查：关键词是否含糊、用户默认了哪些前提、证据来自哪里、有没有相反解释、结论成立或不成立分别意味着什么。

### 3. 收尾整理
问诊结束后，向用户输出：
1. 你最开始问的问题
2. 你真正想解决的问题
3. 已经确认的事实
4. 仍未验证的假设
5. 最可能改变结论的关键变量
6. 一个准确、具体、可以继续行动的新问题

### 4. 等待确认
把新问题呈现给用户，等用户确认后再给出你的判断、理由和下一步行动。用户对问题本身有异议时，继续微调问题，不要抢跑去给方案。

关联：收敛到"两个选项选哪个"时，转 `make-better-decision`；要动手解题时，转 `solve-hard-problem`。
