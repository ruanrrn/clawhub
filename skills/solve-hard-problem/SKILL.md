# 解决难题工具箱：专家会诊 / 第一性原理 / 跨领域借解

> 改编自卡兹克《都Agent时代了，我还是想分享给你这12个最常用的Prompt》。
> 原文：https://mp.weixin.qq.com/s/NAdhdFrUq9-BKelqzqpwBQ

## 选方法
- 问题复杂、横跨多个专业领域，或用户自己视角单一 → **专家会诊**
- 方案满是补丁、被行业惯例和路径依赖绑架、想推倒重来 → **第一性原理**
- 本领域的常规思路都试过了还是卡住 → **跨领域借解**
- 用户指名要用某个方法 → 直接用
- 用户连问题本身都没说清 → 先建议走 `socratic-questioning`（苏格拉底式问诊）
- 收敛到"两个选项选哪个" → 转 `make-better-decision`

三个方法共同前置：需要用户提供问题、已知事实、目标和现实约束。缺关键信息时先问，其中**专家会诊只问一个最关键的问题**。

## 方法一：专家会诊
**先不要直接给方案。**
1. 为这个问题选择**3种真正互补**的专业视角，并说明每种视角为什么必要。不要选三个高度相似的身份；不要模仿或编造真实人物的观点。
2. 让每种视角分别回答：
   - 它怎样重新定义这个问题
   - 它最推荐的解决路径
   - 其他视角最容易忽略的风险
   - 什么新证据会让它改变判断
3. 让三种视角**互相质疑**（真正的信息往往在分歧里），找出：
   - 共同认可的事实
   - 真正的分歧
   - 分歧背后的不同假设
4. 综合输出：
   - 综合后最推荐的方案
   - 适用条件
   - 最大风险
   - 退出条件
   - 第一步行动

## 方法二：第一性原理
1. 把问题拆回最底层，区分四类东西：
   - 已经确认、无法绕开的基本事实
   - 习惯性接受、却没有验证过的假设
   - 真正想实现的目标
   - 现实中的资源与约束
2. **暂时放下行业惯例和现成方案**，只从基本事实、目标和约束出发，重新推导可行路径。
3. 输出：
   - 原方案中只在修补表面的部分
   - 从基本事实重新推导出的新路径
   - 这条路径成立的前提
   - 验证它的第一步

## 方法三：跨领域借解
1. 先剥掉行业术语，把用户的问题抽象成一个人类在其他领域也可能遇到的问题，并找出：
   - 问题的底层结构
   - 真正的核心矛盾
   - 普通解法失效的原因
2. 从历史案例，以及**至少3个彼此距离较远的领域**中，寻找底层结构相似的问题。每个案例说明：
   - 那个领域遇到了什么问题
   - 使用了什么解决机制
   - 与用户的问题相似在哪里
   - 哪些部分可以迁移
   - 什么条件下会失效
3. 选出最值得借用的3种机制，翻译成适合用户当前处境的解决方案，再推荐**一个最值得先试的低成本、可逆实验**。
